# Hacktoberfest Hack Day: Problem Statements

**Theme:** Open-Source AI and Open-Weight Models

Each team of 2–4 participants selects **one** problem statement. Each one must result in a working demonstration at the end of the day.

Participants with no prior coding experience are encouraged to choose Problem 1, 2 or 3.

| No. | Problem Statement | Level | Summary |
|---|---|---|---|
| 1 | [Open Model Showdown](01_open_model_showdown.md) | Foundation (no coding) | Compare three open AI models using a structured test and present the results. |
| 2 | [Build-a-Bot](02_build_a_bot.md) | Foundation (no coding) | Design a custom AI assistant using written instructions, then test and improve it. |
| 3 | [Persona Chatbot](03_persona_chatbot.md) | Beginner | Adapt a working chatbot web application into an assistant with a defined personality. |
| 4 | [Image Classifier](04_image_classifier.md) | Beginner | Build a web application that identifies the contents of a photo from a list of categories. |
| 5 | [Document Question Answering](05_document_question_answering.md) | Intermediate | Build a web application that answers questions from a PDF document, with page references. |

### Level definitions

| Level | What it involves |
|---|---|
| Foundation | No coding. Work is done using free web tools. |
| Beginner | Modify text and settings in starter code that already works. |
| Intermediate | Read and modify a multi-step program. |

### Structure of each problem statement

Each document contains the following sections:

1. Background
2. Objective
3. Scope of Work
4. Key Terms
5. Requirements
6. Approach
7. Expected Deliverables
8. Optional Extensions
